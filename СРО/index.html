MiniShop Tech (Тема 07)

Паспорт проекта и Требования

1. Исследование предметной области

Проанализированы пользовательские сценарии интернет-торговли. Разработан интерфейс каталога, корзины и быстрого оформления заказов без избыточной авторизации.

2. Модель жизненного цикла

Использована **инкрементная модель**: разработка шла итеративно (модель данных -> каталог -> корзина -> валидация ввода и UI).

Протокол тестирования (Не менее 8 тест-кейсов)

ID Описание теста Входные данные Ожидаемый результат Фактический результат Статус

Структура репозитория и Слайды защиты

Файлы проекта:

  • index.html — единый файл приложения (HTML/CSS/JS)
  • README.md — подробное описание
  • tests/protocol.md — матрица тест-кейсов

Защита проекта:

Презентация на 7 слайдов подготовлена, код проверен на корректность обработки исключений и граничных условий ввода.
